Label search/sort, announce results, expose pressed tags and current page. Delete the search route and update current documentation while retaining summaries/title suggestions in this change.
3. **Summary change, independent branch from baseline:** remove the component and endpoint, all three callers and detail wrapper, and current documentation references. Preserve authored descriptions, body, navigation, sharing, media and shared provider instrumentation/dependencies.
4. **Verification:** write search behavior tests before implementation; run Node 24 unit suite, lint, typecheck and webpack production build with synthetic/no-service settings. Exercise keyboard, mobile/desktop, filters/sort/pagination/reset, offline search and removed endpoints through Playwright; record screenshots, index bytes, query timings and bundle totals against the baseline. Independent review both changes before handoff.

Review focus: legacy products with absent status versus draft/archived; punctuation/one-letter queries; AND behavior versus permissive fuzzy results; alphabetical ties and original IDs; stale pagination after reset and product-list changes; accidental edits to authored content or title-suggestion/security code.
